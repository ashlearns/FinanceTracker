 💰 FinanceTracker

FinanceTracker is a Blazor-based personal finance tracking web application that helps users monitor their **cash inflows**, **outflows**, **debts**, and more — with a clean, modern dashboard and rich filtering options.

 Key Features

1. Track **Cash Inflows**, **Outflows**, and **Debts**
2. Prevent outflows if balance is insufficient
3. Automatically clear debts when sufficient inflow is available
4. Tag transactions with **custom or existing labels**
5. Add optional **notes** to any transaction
6. Filter by **type**, **tags**, and **date range**
7. Sort transactions by date
8. Search by **title** with active filters
9. Display total number of transactions and available balance
10. Show totals: **inflows**, **outflows**, **cleared debt**, and **remaining debt**
11. Highlight **highest / lowest** inflow, outflow, and debt
12. List and manage all **pending debts**
13. Filter the dashboard by specific **date ranges**

 Application Overview:

 Transactions Page
- Refresh the page to view all transactions.
- Transactions can be **searched**, **sorted**, and **filtered**.
- A real-time **account summary** is accessible within the page.

Dashboard Page
- Transactions filtered by **title** are displayed as a **chart**.
- **Date-specific transactions** appear in the "Filtered Transactions" section.
- Pending debts can be cleared if there's enough **balance** and **inflow**.
- A complete **financial summary** is available within the dashboard.

Profile Page
- Displays the **logged-in user’s** details.
- Allows updating the **currency** used across the application.
- On registration, the app defaults to **USD ($)**.
